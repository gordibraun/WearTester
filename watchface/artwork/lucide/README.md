# Watch-face Shortcut Icons

`wheat.svg` and `footprints.svg` are from https://github.com/lucide-icons/lucide/tree/main/icons.
The upstream license is included in `LICENSE`.

The corresponding `drawable-nodpi/ic_*.png` files are 96 x 96 transparent PNGs
rasterized from these SVGs with a white stroke. Watch Face Format applies the
button color using `PartImage.tintColor`; the icon shapes are unchanged.
